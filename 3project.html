Memory Nest — LaunchCode Capstone Project

A responsive React-based web application designed to help users save, organize, and revisit personal memories through an intuitive and user-friendly interface. This project highlights clean UI design, component-based architecture, and real-time state updates.

Key Features & Contributions

  • Built dynamic React components that allow users to create, edit, and delete memory entries, improving interaction flow and usability.
  • Implemented state management using React Hooks to ensure smooth, real-time updates and consistent rendering across the application.
  • Designed a clean, accessible, and responsive UI using HTML, CSS, and modern styling techniques to support seamless use across devices.

Tech Stack

JavaScript, React, HTML, CSS, React Hooks, GitHub, VS Code
